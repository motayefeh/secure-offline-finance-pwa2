# PersonalFinance — مدیر مالی شخصی (PWA آفلاین و رمزنگاری‌شده)

برنامه‌ای کاملاً **محلی** برای مدیریت بانک‌ها، بدهی‌ها، اقساط و پرداخت‌ها؛ با داشبورد، گزارش ماهانه
(«چقدر باید به هر بانک واریز کنی»)، رمز عبور، قفل خودکار، ثبت رویدادها و پشتیبان‌گیری رمزنگاری‌شده.

> هیچ سرور، دیتابیس آنلاین یا API خارجی وجود ندارد. همه داده‌ها با **AES-GCM-256** رمزنگاری و در
> حافظه محلی مرورگر (localStorage) ذخیره می‌شود.

---

## اجرا در VS Code / Visual Studio

```bash
npm install      # نصب وابستگی‌ها
npm run dev      # اجرای محیط توسعه  (http://localhost:5173)
npm run build    # ساخت نسخه نهایی در پوشه dist
npm run preview  # پیش‌نمایش نسخه نهایی (برای تست PWA و آفلاین)
```

> برای نصب به‌عنوان اپ (اندروید/ویندوز) و تست حالت آفلاین، از `npm run preview` یا هر هاست استاتیک
> (GitHub Pages، Netlify، IIS، آپاچی…) استفاده کنید. نصب PWA نیاز به `https` یا `localhost` دارد.

نصب روی اندروید: منوی کروم → **Add to Home screen / نصب برنامه**
نصب روی ویندوز: کروم/اج → آیکون نصب در نوار آدرس

برای اجرای کاملاً مستقل روی اندروید، این پروژه Capacitor هم دارد. در این حالت برنامه به‌صورت APK روی
گوشی نصب می‌شود و برای اجرا به کامپیوتر، Wi-Fi یا سرور نیاز ندارد. راهنمای کامل در بخش «ساخت APK» آمده است.

## امنیت

| لایه | توضیح |
| --- | --- |
| کلید | مشتق از رمز عبور با `PBKDF2-SHA256` و ۳۱۰٬۰۰۰ دور (Web Crypto) |
| رمزنگاری | `AES-GCM-256` با IV تصادفی برای هر ذخیره‌سازی |
| حافظه کلید | کلید فقط در RAM نگه داشته می‌شود؛ در قفل خودکار پاک می‌شود |
| قفل خودکار | پیش‌فرض ۵ دقیقه بی‌فعالیتی (قابل تنظیم ۱ تا ۳۰ دقیقه) + قفل هنگام ترک برنامه |
| ورود ناموفق | افزایش تدریجی زمان قفل تا ۱۵ دقیقه |
| داده حساس | شماره کارت/حساب به‌صورت ماسک نمایش داده می‌شود و امکان «مخفی‌کردن مبالغ» هست |
| پشتیبان | فایل JSON رمزنگاری‌شده با رمز مستقل + بازیابی کامل (حتی در حالت قفل) |
| رویدادها | ثبت لاگ ورود، تغییرات، پرداخت‌ها و عملیات امنیتی داخل گاوصندوق |

**رمز عبور قابل بازیابی نیست**؛ تنها راه بازگشت داده‌ها فایل پشتیبان است.

## ساخت APK مستقل اندروید

پیش‌نیازها:

- Node.js LTS
- Android Studio
- Android SDK و SDK Platform مناسب دستگاه
- فعال‌کردن Developer options و USB debugging روی گوشی برای نصب مستقیم

در ترمینال، داخل پوشه پروژه اجرا کنید:

```powershell
npm.cmd install
npm.cmd run build
npx.cmd cap add android
npx.cmd cap sync android
npx.cmd cap open android
```

دستور `npx.cmd cap add android` فقط اولین بار اجرا می‌شود. اگر پوشه `android` از قبل ساخته شده، آن را دوباره اجرا نکنید.

سپس در Android Studio:

1. منتظر بمانید Gradle Sync کامل شود.
2. گوشی را با کابل وصل کنید و USB debugging را تأیید کنید، یا یک Emulator بسازید.
3. دستگاه را از نوار بالای Android Studio انتخاب کنید.
4. روی دکمه سبز **Run** بزنید.

برای گرفتن فایل APK قابل انتقال به گوشی:

1. از منوی Android Studio گزینه `Build > Build APK(s)` را بزنید.
2. فایل خروجی معمولاً در مسیر زیر قرار می‌گیرد:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

3. فایل APK را به گوشی منتقل و نصب کنید.

هر بار که کد React را تغییر دادید:

```powershell
npm.cmd run build
npx.cmd cap copy android
```

اگر وابستگی Capacitor یا تنظیمات Android تغییر کرد، به‌جای `copy` اجرا کنید:

```powershell
npx.cmd cap sync android
```

بعد از نصب APK، برنامه مستقل است: اطلاعات در حافظه همان گوشی ذخیره می‌شود، اینترنت لازم نیست و
خاموش بودن کامپیوتر اثری ندارد. برای انتقال اطلاعات بین کامپیوتر و گوشی از بخش تنظیمات برنامه،
فایل پشتیبان رمزنگاری‌شده بگیرید و در گوشی Restore کنید.

## انتشار خودکار روی GitHub Pages

این پروژه فایل workflow آماده در `.github/workflows/deploy-pages.yml` دارد. بعد از انتشار روی GitHub،
هر بار که روی شاخه `main` یا `master` push کنید، نسخه `dist` ساخته و منتشر می‌شود.

1. در GitHub یک repository جدید بسازید؛ مثلاً `personal-finance`.
2. کل پروژه را در همان repository قرار دهید. فایل‌های `package.json`، `src`، `public` و پوشه `.github`
   باید در ریشه repository باشند.
3. به `Settings > Pages` بروید.
4. در بخش `Build and deployment`، گزینه `Source` را روی **GitHub Actions** قرار دهید.
5. به تب `Actions` بروید و workflow با نام `Deploy PersonalFinance to GitHub Pages` را اجرا یا بررسی کنید.
6. بعد از موفقیت، آدرس سایت معمولاً این است:

```text
https://USERNAME.github.io/REPOSITORY/
```

مثلاً:

```text
https://ali.github.io/personal-finance/
```

مسیرهای مانیفست، آیکون و Service Worker نسبی هستند؛ بنابراین برنامه در repositoryهای GitHub Pages با
نام‌های متفاوت هم درست باز می‌شود. بعد از اولین بازشدن در Chrome، می‌توانید از منوی مرورگر گزینه
**Install app / Add to Home screen** را بزنید. پس از نصب PWA، برای اجرای روزمره اینترنت لازم نیست.

نکته امنیتی: GitHub Pages فقط فایل‌های برنامه را منتشر می‌کند و داده‌های مالی شما را نگه‌داری نمی‌کند.
اطلاعات هر دستگاه جداست. برای انتقال داده بین دستگاه‌ها از Backup رمزنگاری‌شده داخل خود برنامه استفاده کنید.

## امکانات

- **داشبورد**: جمع واریزی ماه، بدهی باقی‌مانده، پیشرفت تسویه، هشدار سررسیدهای نزدیک/معوق،
  نزدیک‌ترین اقساط، نمودار روند ۶ ماه و سهم بانک‌ها.
- **بانک‌ها**: بانک/صندوق/شخص، شعبه، شماره کارت و حساب و شبا، تلفن، رنگ شناسه، یادداشت.
- **بدهی و اقساط**: وام، قسطی، چک، اقساط کارت اعتباری، قرض شخصی؛ مبلغ قسط و کارمزد، تعداد و
  اقساط پرداخت‌شده، روز سررسید شمسی، پیشرفت و ثبت سریع «یک قسط پرداخت شد».
- **پرداخت‌ها**: ثبت با تاریخ شمسی، نوع (قسط/اضافه/جریمه/واریز)، روش پرداخت، شماره رسید،
  فیلتر و جستجو، خروجی CSV.
- **گزارش‌ها**: جدول «مبلغ دقیق واریزی به هر بانک» با درصد سهم، دوره‌های ماه/۳ماه/۶ماه/سال،
  نمودارها، تحلیل و پیش‌بینی (مدت تسویه، میانگین‌ها)، خروجی CSV و چاپ.
- **تنظیمات**: تم تیره/روشن، ۱۰ رنگ اصلی، قالب اعداد فارسی/لاتین، واحد پول، قفل خودکار،
  روز هشدار سررسید، تغییر رمز (رمزنگاری مجدد کامل)، پشتیبان/بازیابی، پاک‌سازی کامل، داده نمونه.
- **PWA**: مانیفست + Service Worker با کش آفلاین، آیکون، قابل نصب روی اندروید/ویندوز.

## نکته فنی

- ذخیره‌سازی: `localStorage` با کلیدهای `pf.meta.v1` (نمک، دورهای PBKDF2، شمارنده خطا) و
  `pf.vault.v1` (متن رمزنگاری‌شده گاوصندوق). برای داده‌های بزرگ‌تر می‌توان همین دو بلوک را به
  IndexedDB منتقل کرد؛ ساختار کد این امکان را حفظ کرده است.
- تاریخ‌ها به‌صورت میلادی (`yyyy-mm-dd`) ذخیره و در رابط کاربری شمسی نمایش داده می‌شوند.
- روز سررسید ماهانه (۱ تا ۳۱) شمسی است و نزدیک‌ترین سررسید به‌صورت خودکار محاسبه می‌شود.
